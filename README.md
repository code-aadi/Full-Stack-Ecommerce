# Full-Stack E-Commerce Platform

A full-stack e-commerce application that I am currently building while learning and implementing real-world development concepts.

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Mongoose

## Features

- User authentication
- Access & refresh token authentication
- Product listing and filtering
- Product details
- Cart management
- Wishlist
- Checkout
- Payment integration
- Admin panel
- Product management
- Order management
- Stock validation

## Status

🚧 This project is currently under development.

I am progressively building and pushing features as they are completed.
